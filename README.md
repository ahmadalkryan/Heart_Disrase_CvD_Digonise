## 🎯 نظرة عامة

هذا المشروع يهدف إلى مساعدة الأطباء والمرضى في الكشف المبكر عن أمراض القلب باستخدام الذكاء الاصطناعي. تم تدريب ثلاثة نماذج مختلفة على بيانات حقيقية لأكثر من 900 مريض، ويمكن استخدامها للتنبؤ بخطر الإصابة بدقة تصل إلى 89.32%.

### حالات الاستخدام

| الاستخدام | الوصف |
|-----------|-------|
| 🏥 **المستشفيات** | أداة مساعدة للأطباء في التشخيص |
| 🏪 **العيادات** | فحص أولي سريع للمرضى |
| 📱 **التطبيقات** | يمكن دمجها في تطبيقات الهواتف |
| 🌐 **المواقع** | يمكن دمجها في المواقع الطبية |
